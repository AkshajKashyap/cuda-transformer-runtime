# Portfolio measurement report — v1.0.0

## Context

Measurements were collected on WSL2 Ubuntu with an NVIDIA GeForce RTX 3050
Laptop GPU (compute capability 8.6), CUDA Toolkit 13.3 / nvcc 13.3.73, GCC
13.3, CMake 3.28, and Ninja. The runtime uses FP32 and one decoder block with
batch 1, hidden 256, 4 heads × 64, and MLP intermediate 512.

Real-GPU correctness result: **18/18 CTests passed**.

## Profiling summary

Nsight first showed three allocation/free pairs per incremental token. Rotated
Q, rotated K, and score scratch moved to `IncrementalAttentionWorkspace`, so
steady-state production decode has zero `cudaMalloc` and zero `cudaFree` calls.
The next trace identified long-context P×V as the primary custom-kernel
bottleneck; at history 1024 the serial P×V measurement was about 94 µs. The
cooperative reduction was then benchmarked independently and integrated with
the measured threshold above.

Measurements are dated in the context of the v1.0.0 portfolio release. Laptop
DVFS, thermals, power limits, and other GPU activity can change results.
